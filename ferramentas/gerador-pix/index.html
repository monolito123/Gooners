Gerador de QR Code Pix

Crie QR Code Pix e Pix Copia e Cola com valor, para receber pagamentos.

Como usar — Gerador de QR Code Pix

  1. Informe o tipo e a chave Pix.
  2. Preencha o nome do recebedor, a cidade e, se quiser, o valor.
  3. Copie o Pix Copia e Cola ou baixe o QR Code para receber o pagamento.

Perguntas frequentes

O QR Code Pix gerado é seguro?

O código é gerado no seu navegador no padrão BR Code do Banco Central. Quem paga vê o nome do recebedor no app do banco antes de confirmar.

Posso gerar Pix sem valor definido?

Sim. Deixe o valor em branco e quem paga digita o valor no momento do pagamento.

Esta ferramenta é gratuita?

Sim, é totalmente gratuita, sem cadastro e sem limite de uso.

Os dados que digito ficam salvos?

Não. O processamento acontece no seu navegador e nada é enviado ou armazenado em servidores.
